# Облако: приём данных в Google Таблицу

Приложение по желанию пользователя (галочка на стартовом экране, по умолчанию выключена) отправляет анонимные данные заряда в Google Таблицу владельца.

1. Создайте новую Google Таблицу.
2. Расширения → Apps Script. Удалите всё, вставьте содержимое `Code.gs`, сохраните.
3. Развернуть → Новое развёртывание → тип «Веб-приложение»: выполнять от имени «Я», доступ «Все». Скопируйте адрес вида `https://script.google.com/macros/s/…/exec`.
4. Впишите адрес в `index.html` в константу `CLOUD_URL`.

Листы `samples`, `events`, `sessions` создаются сами. В `sessions` по строке на сессию: сводка и вердикт («норма», «перекос», «перенапряжение», «глубокий разряд», «были тревоги»).

Что отправляется: напряжения ячеек (раз в 30 с), ток, события, химия, ёмкость, случайный номер сессии. Имени устройства, геолокации и контактов нет.
