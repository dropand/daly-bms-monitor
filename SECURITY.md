# Безопасность

Приложение статическое: на сайте нет сервера и базы, взламывать нечего. Данные BMS читаются по Bluetooth и остаются на устройстве, пока пользователь сам не включит отправку.

**В приложении**
- Content-Security-Policy: скрипты только с этого же сайта, сетевые запросы только к `script.google.com`; чужой код встроить нельзя.
- Весь текст из BMS и из хранилища телефона выводится с экранированием; сохранённые данные проверяются на тип и диапазон при загрузке.
- Запросы без cookie и без Referer.
- Отправка в облако: только по галочке, не чаще раза в минуту с устройства, только новые данные.

**В приёмнике (`cloud/Code.gs`)**
- Строгая проверка формата и диапазонов, лишнее отбрасывается.
- Не чаще одного запроса в 20 с с одной сессии и 1500 запросов в час на скрипт.
- Повторы не создают дублей; текст событий очищается от формул таблицы (`=`, `+`, `-`, `@`).

**Что защитить нельзя:** адрес приёма публичный, поэтому посторонний может отправить выдуманные данные. Лимиты не дают забить таблицу, но верить строкам из `sessions` как проверенным нельзя.
